# DEAD OR ALIVE 1 — Model 2 move-list reference

Japanese transcription, English translations, and numeric inputs from the 17 supplied move-list images, with name verification against the subsequently supplied Gamest Mook 57 scans. Includes Kasumi, Gen Fu, Leifang, Bayman, Ryu Hayabusa, Jann Lee, Tina, Zack, and Raidou.

**Translation status:** English names are unofficial translations or English renderings of the printed katakana names. Chinese martial-arts names are rendered for meaning rather than presented as official localized names. Thai-derived names retain a romanized form with an approximate English gloss. Names describe the source text; they are not independently verified descriptions of the animations.

**Transcription status:** Commands and categories follow the original small charts. Gamest Mook 57 resolves 13 of the 14 previously flagged name entries; the remaining entry, `LEI-S06`, has a clear printed reading (テッサ) but an unresolved second kanji. Name corrections and source variants are documented in the reconciliation section below. English translations remain unofficial. Repeated names, unusual spellings, and unusual button combinations have been retained. This is a transcription of these charts, not a claim that the charts list every move in every Model 2 revision.

## Notation

Directions use the numeric keypad with the character facing right. Mirror left/right when the character faces left.

| Direction | Number | Direction | Number | Direction | Number |
| --- | --- | --- | --- | --- | --- |
| ↖ Up-back | `7` | ↑ Up | `8` | ↗ Up-forward | `9` |
| ← Back | `4` | Neutral | `5` | → Forward | `6` |
| ↙ Down-back | `1` | ↓ Down | `2` | ↘ Down-forward | `3` |

| Notation | Meaning |
| --- | --- |
| `P` | Punch |
| `K` | Kick |
| `H` | Hold button, using the source's H notation |
| `PP`, `PK` | Successive presses, read left to right |
| `H+P`, `P+K`, `H+P+K` | Simultaneous buttons; plus signs appear in the chart |
| `66P` | Forward, forward, Punch |
| `236P` | Down, down-forward, forward, Punch |
| `[2]`, `[3]` | A **filled blue direction arrow** in the source, distinguished from its ordinary hollow arrows. Commonly denotes a held/crouching direction; the supplied color guide does not define this symbol or its timing. Brackets preserve that distinction without supplying an unverified frame requirement. |
| `360H` | One full lever rotation, then H; the source does not specify a starting direction or rotation direction |
| `/` | Alternative commands printed for the same move/condition |
| Space in `H+K H+K` | Repeat the simultaneous combination as successive inputs |
| “During …” | Follow-up performed during the named preceding technique |
| “From behind the opponent” | Attacker is behind the defender; this does not mean the attacker is back-turned |
| “Opponent's mid K” | Source says 敵中Kに: against a middle-height kick. It does not specify a detailed hold timing window. |
| Down attack | Category used for attacks against a downed opponent; retain that condition when comparing duplicate commands |

**Reference IDs** such as `KAS-S01` are document identifiers only. They are **not ACTCODEs, MOVE_IDs, character IDs, or table indices from the game**. A row can retain several alternative commands; separately stated conditions sometimes receive separate rows.

## Research notes

- A matching input alone does not establish a shared animation or ACTCODE. Keep the character, category, and condition with every reference.
- For example, Kasumi's `KAS-S08` **飛龍脚** (“Flying Dragon Kick”) and `KAS-D01` **鷹爪脚** (“Hawk-Claw Kick”) both print `8K`. The chart places them in different categories; the latter is a down attack.
- Gen Fu's `GEN-S12` and `GEN-S19` print the same name **虎蹲山**, now confirmed by Gamest Mook 57 with the reading コソンザン, but give `33P` and `3P3P` respectively. Both source entries remain separate.
- Gen Fu's `GEN-S13` prints `66HP` with no plus sign between H and P. Do not silently convert it to `66H+P` when testing.
- Jann Lee's **エンター・ザ・ドラゴン** (“Enter the Dragon”) is on a green row, so it remains under down attacks here.
- No damage, frame data, hit levels, ACTCODE values, or inferred animation identities have been added. The only explicitly printed attack-height condition retained here is the mid-K condition on several joint-lock entries.
- To search quickly, use the character prefix (`KAS`, `GEN`, `LEI`, `BAY`, `RYU`, `LEE`, `TIN`, `ZAC`, `RAI`), a Japanese name, an English name, or the numeric input. Search `LEI-S06` or `unresolved` for the remaining unclear spelling. See the reconciliation section for resolved readings and corrections.
